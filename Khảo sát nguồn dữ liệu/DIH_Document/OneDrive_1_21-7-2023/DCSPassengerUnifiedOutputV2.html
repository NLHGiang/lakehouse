Dynamic Intelligence Hub API and Data Models - DCS Passenger

Overview

This document describes the OpenAPI for: 1. GET for DCS Passenger data 2. Data models for the information pushed out by Amadeus for DCS Passenger

Version information

Version : 2.2.0

URI scheme

Host : airlines.api.amadeus.com
BasePath : /v2
Schemes : HTTPS

Consumes

  • application/json

Produces

  • application/vnd.amadeus+json

Paths

DCS Passenger Data Push

POST /departure-control/dcs-passenger-feed

Description

Model for the DCS Passenger data push feed. Please be aware this is NOT a POST API, rather this explains the format of the data pushed out by Amadeus.

Responses

HTTP Code Schema

200

DcsPassengerPush

Tags

  • Data Push Models

Coupon

A coupon refers to a product that has been issued in the current travel document. In tickets, a coupon refers to a flight segment. An airline ticket portion that bears the notion "good for passage", or in the case of an electronic ticket, the electronic coupon indicates the particular places a passenger is entitled to be carried. A single ticket/document number may contain up to 4 segments. For tickets/documents with more than 4 segments of travel, a conjunction ticket is required to continue the itinerary. In EMDs, a coupon can refer to an ancillary service, an upgrade, a fee or a residual value. * soldSegment - Original image of the coupon at first issuance of the document. * currentSegment - Latest image of the coupon in case it has been subject to modification[s] such as revalidation e.g. change of flight number. * usedSegment - Image of the coupon when its status is considered as used i.e. either flown [B] or exchanged [E], refunded [RF], printed [PR], print exchange [PE], converted to Flight Interruption Manifest [G], closed [CLO], voided [V].
